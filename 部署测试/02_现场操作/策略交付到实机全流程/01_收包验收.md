# S0 收包验收（新策略包到手）

在 caolin 服务器（项目挂载）即可完成；只读，不碰任何设备。

## 1. 包完整性

同事按 v3 清单（《AS2-W训练到部署交付清单_v3_通用核心与按需模块.md》，本目录上一级）组织的包应含：

```text
<policy-id>/
  README.md  manifest.yaml  handoff.md  SHA256SUMS.txt
  model/     (checkpoint + policy.onnx + export脚本 + metadata + parity记录)
  runtime/   (observations.csv + joints.csv + effective_runtime.yaml + entry_exit.md + 可选模块)
  replay/    (native_samples.npz 或等价回放夹具 + verify_parity.py)
  simulation/ (资产 + 复跑入口 + 原始156例等证据)
  source/    (训练源码快照/commit + resolved配置)
```

**先跑他们自带的校验**（在包根目录）：
```bash
python3 -B checks/verify_package.py      # SHA + 溯源
python3 -B replay/verify_parity.py       # ONNX/观测/目标/C++ 映射 parity
```
任一失败 → 待补件，只读研究，不进入后续阶段（v3 合同 R0 门槛）。

## 2. 必读的合同字段（决定后续所有工作）

| 文件 | 必须弄清的点 |
|---|---|
| `runtime/observations.csv` | 观测维度/顺序/坐标/缩放/裁剪顺序/上一动作语义；**轮位槽是否补零**（mlp57: obs[21:25] 恒零）；重力符号约定（R1199 站立 z=+1，mlp57 站立 z=−1，**两家相反**） |
| `runtime/joints.csv` | 关节序（FR-first 按腿分组 vs FL-first 按类型分组）；动作缩放/偏置（R1199: 0.35 偏置 [0,0.8,−1.6] 轮×16；mlp57: [0.125,0.25,0.25] 偏置 [0,0.65,−1.3] 轮×5）；kp/kd（40/1、55/2…）；力矩限 |
| `runtime/effective_runtime.yaml` | 全部运行开关实值（站姿补偿/停车/包装）；**与训练 actual_runtime_flags 逐项一致**（硬规则） |
| `runtime/entry_exit.md` | 入口姿态/高度/初速；零命令语义（R1199 有主动轮锁，mlp57 纯靠静摩擦）；退出/失联由谁负责 |
| `model/metadata.json` | 维度/频率/网络结构/SHA |
| `handoff.md` | 已验证/未验证/not_run 的范围；sim2sim 是否已跑 |

## 3. 验收输出

写一页验收记录到 `部署测试/04_调试记录/INDEX.md`：
- 包路径、校验结果、权重/ONNX SHA、维度/频率
- **差异点清单**（与已有策略逐项对比，见 02 文档的坑列表）
- 判定：进入 S1 / 待补件
