# AS2-W 与 Go2-W / B2-W：模型资产与训练配置深度对比

**日期**：2026-11-12
**范围**：`部署参考/unitree_ros` 完整仓库（HEAD `41dec58`）、`部署参考/as2w_mlp57_flat_model2700_v1_20261112`（B2W 配方训练线）、`部署测试/06_训练协作/R1199_real_robot_feedback_20261112`（R1199 训练合同）
**目的**：回答一个问题——AS2-W 的模型和训练配置里，哪些信息是**缺失**的，哪些是**从别的机型直接搬过来**的，以及这些差异会不会解释实机上看到的姿态跳变和滚动抖动。

---

## 0. 结论摘要

1. **仓库已完整拉取并可复现**：`unitree_ros` 共 1597 个文件、约 1.7 GB，HEAD `41dec58`（2026-11-06）。训练包锁定的是 `4ddbf6d`（2026-08-24）；`git diff 4ddbf6d HEAD` 对 as2w / as2 / go2w / b2w 四个目录**为空**，即训练用的 AS2W URDF 与当前 master 逐字相同，这一点可以放心引用。

2. **AS2-W 的腿是 AS2 的腿，不是 Go2-W 的放大版**。髋/大腿/小腿的关节原点、连杆长度（0.2202 / 0.1054 / 0.212 / 0.212 m）、限位（髋 ±0.785、前大腿 −2.0…3.492、后大腿 −1.3…4.19、小腿 −2.7677…−0.8133）和力矩上限（60 / 60 / 90 N·m）与 AS2 **逐位相同**，只有速度上限从 24 / 24 / 16 提到了 25 / 25 / 16.67 rad/s。

3. **AS2-W 的轮子和 Go2-W 的轮子尺寸完全一致**（直径 172 mm、宽 51.8 mm，半径 0.086 m，两者网格包围盒差 ≤ 0.2 mm），但 AS2-W 的轮转动惯量是 Go2-W 的 **2.15 倍**。按几何反算回转半径：AS2-W 0.765 r（合理），Go2-W 0.559 r（接近“质量全在轮毂”，与 172 mm 轮胎不符）。这两个数不可能同时正确。

4. **AS2-W 的轮速上限 98.47 rad/s 折合 8.47 m/s**，是 Go2-W（30.1 rad/s → 2.59 m/s）的 3.3 倍、B2-W（50 rad/s → 5.64 m/s）的 1.5 倍；而训练限速只有 1.0 m/s。这个数需要确认到底是“输出侧限值”还是电机空载转速。

5. **官方 MJCF 里本来就有腿电机的 armature / damping / frictionloss**（`as2.xml`：髋/大腿 0.026 / 0.2 / 1.0，小腿 0.038 / 0.5 / 2.0），AS2-W 的 URDF、Isaac 配置、部署 MuJoCo 三处**全部没有用**。这是现成可补、且与实机抖动最相关的一条缺失。

6. **训练配置确实存在整段搬运**：mlp57 那条线直接继承 B2W 的资产配置和环境配置，审计脚本甚至断言“奖励权重必须等于 B2W”；而 B2W 是 82 kg / 200–320 N·m 的机器，AS2-W 是 26 kg / 60–90 N·m。R1199 那条线换了 65 维接口和更紧的域随机化，但安全包络仍是“URDF × 0.9 + 仿真膝面偏移”，文件里自己标注 `simulation_urdf_not_hardware_calibration`。

### 3.2 血缘一：AS2 → AS2-W（质量差 8.36 kg 的去向）

AS2-W 的 26.0 kg 可以精确拆成 AS2 的 17.64 kg 加上 8.36 kg：

| 增重项 | 单件增量 | ×4 | 说明 |
|---|---|---|---|
| 本体 | +1.28 | — | 8.80 → 10.08 |
| 髋 | +0.055 | +0.22 | 0.695 → 0.750 |
| 大腿 | +0.160 | +0.64 | 1.25 → 1.41 |
| 小腿 | +0.880 | +3.52 | 0.22 → 1.10，**轮毂电机并入小腿** |
| 足 | +0.550 | +2.20 | 0.045 → 0.595，**足变成轮** |
| JT128 | +0.50 | — | 顶部 128 线雷达 |
| 合计 | | **+8.36** | 17.64 + 8.36 = 26.00 |

这条链路说明两件事：

- **AS2-W 的腿是 AS2 的腿加轮毂**，不是重新设计的。小腿从 0.22 kg 涨到 1.10 kg（+0.88），正好是轮毂电机的量级；足从 0.045 变成 0.595 kg 的轮子。
- **AS2-W 的 12 个腿关节参数与 AS2 完全同源**，因此 AS2 官方 MJCF 里的关节阻尼/电枢/摩擦（见第 4 节）对 AS2-W 的腿**直接适用**，不需要额外辨识。

### 3.3 血缘二：Go2 → Go2-W（3.436 kg，逐项可对上）

| 变化 | 计算 | 质量 |
|---|---|---|
| 去掉 12 个转子 link | −12 × 0.089 | −1.068 |
| 加上 4 个轮毂电机（固定 link） | +4 × 0.646 | +2.584 |
| 足 0.040 → 轮 0.520 | +4 × 0.480 | +1.920 |
| **合计** | | **+3.436** |

与 19.523 − 16.087 = 3.436 **完全相等**。

这里有一条容易被忽略的信息损失：**Go2 用 12 个 0.089 kg 的转子固定 link（命名以 `_rotor` 结尾）来表示转子惯量，Go2-W 把这 12 个 link 全删了，却没有用 armature 补回来**。也就是说 Go2-W 的腿在仿真里比 Go2 更“轻”，而 AS2-W（2026 年）沿用了 Go2-W 这种做法，同样没有转子惯量。

### 3.4 轮子：同尺寸、不同惯量

| 项目 | AS2-W | Go2-W | B2-W |
|---|---|---|---|
| 轮网格包围盒 | 171.7 × 51.8 × 172.0 mm | 171.9 × 51.8 × 171.9 mm | 225.8 × 50.0 × 225.8 mm |
| 半径 | 0.0860 m | 0.0860 m | 0.1129 m |
| 轮质量 | 0.595 kg | 0.520 kg | 1.083 kg |
| 绕轴惯量 Iyy | 0.0025769 | 0.0012000 | 0.007776 |
| 回转半径 √(I/m) | 0.0658 m（**0.765 r**） | 0.0480 m（**0.559 r**） | 0.0847 m（0.751 r） |
| 力矩 / 速度上限 | 15 N·m / 98.47 rad/s | 23.7 N·m / 30.1 rad/s | 20 N·m / 50 rad/s |
| 折合轮缘力 / 线速度 | 174 N / **8.47 m/s** | 276 N / 2.59 m/s | 177 N / 5.64 m/s |
| 四轮合力 / 整机重量 | 2.74 | 5.76 | **0.88** |
| 功率（τ·ω） | 1477 W | 713 W | 1000 W |

三个判读：

1. **AS2-W 与 Go2-W 的轮是同一尺寸规格**（差 ≤ 0.2 mm），几乎可以肯定是同一套轮系设计；两者的质量差 14%（0.595 vs 0.520）可能来自轮胎/轮毂配置不同。
2. **两者的绕轴惯量差 2.15 倍**。同样 172 mm 的轮子，回转半径不可能一个 0.765 r、一个 0.559 r。AS2-W 的 0.765 r 接近“薄壁圆环 + 轮毂”，是合理的；Go2-W 的 0.559 r 相当于质量几乎全部集中在半径 5 cm 以内，与带轮胎的轮子不符。**Go2-W 的这个数大概率是错的或只算了轮毂**。
3. **AS2-W 的 98.47 rad/s 非常可疑**。它与 Go2-W 的 30.1 差 3.27 倍，折算线速度 8.47 m/s；一台 26 kg、训练限速 1.0 m/s 的机器不需要 8.5 m/s 的轮速上限。可能是电机空载转速、或旧型号数据，需要厂商确认。
4. 反过来，**B2-W 的四轮合力只有自重的 0.88 倍**，意味着仅靠轮子最大只能爬约 41° 的坡、且几乎不能加速；这解释了为什么 B2W 的轮式策略主要靠“滚动 + 腿辅助”，也提醒不要把 B2W 的轮子调参经验直接搬到 AS2-W（后者是 2.74 倍，余量大得多）。

### 3.6 后腿不对称：限位是真的，惯量存疑

AS2-W 前后腿有两处不对称：

| 项 | 前腿 | 后腿 | 判断 |
|---|---|---|---|
| 大腿限位 | −2.0…3.492 | −1.3…4.19 | **真实**。实机止点实测：前 −2.048 / −2.022（比 URDF 还低 0.02–0.05 rad），后 −1.317 / −1.336；上限 +4.188 / +4.189 对 4.19 |
| 小腿质量 | 1.100 | 1.100 | 相同 |
| 小腿质心 z | −0.16915 | **−0.18449** | 差 15.3 mm |
| 小腿 Iyy | 0.0067667 | **0.0050599** | 差 25.2% |
| 小腿网格包围盒 | 80.2 × 70.0 × 283.7 mm | **完全相同** | 同形不同惯量 |
| 大腿质心 y / Iyy | −0.02408 / 0.006131 | −0.022228 / 0.006272 | 小差异，同包围盒 |

AS2（无轮版）四个小腿的质心与惯量**完全一致**，说明这种前后差异是 AS2-W 阶段才出现的。结合“包围盒相同、质量相同、惯量差 25%”，有三种可能：

1. 前后小腿确实是不同铸件（例如后腿多了轮毂电机的安装座），只是外形包络相同；
2. 前后惯量来自不同的 CAD/测量批次；
3. 其中一组是抄错或手填的。

现有资料无法区分。**建议**：用 CAD 干涉体积或实测摆锤法核对后小腿；在核对前，任何“AS2-W 前后腿动力学不对称”的结论都不要建立在这组数上。

## 4. 官方 MJCF 里有、AS2-W 里没有的参数

`robots/as2_description/as2.xml` 是官方给 AS2 的 MuJoCo 模型，里面有完整的关节级参数：

| 模型 | 关节类 | damping | armature | frictionloss |
|---|---|---|---|---|
| **AS2** | hip | 0.2 | **0.026** | 1.0 N·m |
| | thigh | 0.2 | **0.026** | 1.0 N·m |
| | calf | 0.5 | **0.038** | 2.0 N·m |
| A2 | hip / thigh | 0.2 | 0.030 | 1.0 N·m |
| | calf | 1.0 | 0.030 | 3.0 N·m |
| B2（MJCF） | 全部 | 1.0 | 0.100 | — |
| H1（MJCF） | 全部 | 1.0 | 0.100 | — |

**MJCF 的覆盖范围**：全仓库带 MuJoCo 模型的只有 `a2_description`、`as2_description`、`b2_description_mujoco`、`g1_description`（13 个）、`h1_description`、`h1_2_description`、`h2_description`（`H2_loop.xml`）。**三个轮式四足 as2w / go2w / b2w 一个 MJCF 都没有**——Go2-W 的目录里只有 `urdf/`、`dae/`、`launch/`、`config/`，唯一的 `.xml` 是 ROS 的 `package.xml`。所以轮关节的 armature / 阻尼 / 摩擦在任何官方文件里都查不到，只能靠台架辨识。

**AS2-W 的三处模型都没有这些值**：

- `as2w.urdf`：没有 `<dynamics>`，没有 armature 字段；
- Isaac 训练配置（`as2w_robot.json` / resolved_env.yaml）：`armature: null`、`friction: 0.0`；
- 部署 MuJoCo（`as2w-flat-rerun/assets/as2w_flat.xml`）：`<joint>` 上没有 `armature` / `damping` / `frictionloss`。

而 AS2-W 的 12 个腿关节与 AS2 **是同一套电机**（力矩 60/60/90 完全相同，速度只差 4%），所以这组数可以直接借用，属于“零成本补全”：

> 建议：AS2-W 腿关节采用 `hip/thigh: armature 0.026, damping 0.2, frictionloss 1.0`；`calf: armature 0.038, damping 0.5, frictionloss 2.0`。轮关节没有官方数据，需要单独辨识（见 6.3）。

注意：`armature` 在 Isaac 里是 `armature` 字段，在 MuJoCo 里是 joint 的 `armature` 属性，两者物理含义相同（转子惯量折算到关节侧），但单位都是 kg·m²，不是无量纲。

### 5.3 按 26 kg 复算，哪些奖励的量级变了

以 `joint_torques_l2` 为例：B2W 的 τ 量级约 100 N·m，AS2-W 约 30 N·m。同样的权重 −1e−5：

- B2W：−1e−5 × 100² = −0.1 / 关节
- AS2-W：−1e−5 × 30² = −0.009 / 关节

即**力矩正则的实际强度只有 B2W 的 1/11**。加速度项同理（1/11 左右），功率项同理。而 `upward` 是纯姿态项（与尺度无关），AS2-W 却拿了 3 倍于 Go2-W 的权重。

净效果：**线 A 的策略在训练时“姿态被强烈拉住、力矩/加速度几乎不被约束”**。这与实机上看到的“停走时高/低腿姿反复切换 + 关节抖动”在方向上是一致的——当然这只是一个待验证的假设，不是结论。

### 5.4 默认站姿的三个版本

| 来源 | hip | thigh | calf | 说明 |
|---|---|---|---|---|
| 训练 nominal（线 A） | 0 | 0.65 | −1.3 | 文件自注 “not a measured pose” |
| 实机原厂站姿实测 | ±0.12 | 0.60 | −1.23 | 11:41 静止窗口均值 |
| 部署 `deploy.yaml`（R1199） | 0 | 0.80 | −1.60 | 与另两者都不同 |

三个值放在一起，说明“默认姿态”目前是**约定**而不是**标定**。训练用的 0.65/−1.3 折算轮心高度 0.3375 m（机身 0.4235 m），实测站姿折算 0.3463 m（机身 0.4323 m），比训练高 9 mm；部署的 0.8/−1.6 折算 0.2954 m（机身 0.3814 m），比训练**低** 42 mm。三者不是同一个姿态。
