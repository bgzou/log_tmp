# AS2-W R4000 实机长转轮差 ~10× 缺口根因调查报告

2026-11-13 | 调查对象：会话 `20261113-114335_r4000`（rolling-4000-stage020-research，包络 ±0.4 m/s / ±0.1 rad/s，120 s PolicyWalk）
任务约束：仅离线复算/源码审计/仿真对照；不启动长训、不改线上部署、不操作实机。

## 首段结论

**这 ~10 倍缺口不在策略推理、包装或发布链的任何一级，而全部落在"最终发布轮速命令 → 实测轮速差"这一级，且由两个可分离的因子相乘构成：**

1. **轮速环的结构性力矩上限（约 3 倍，实机与仿真共有）**：转向差动唯一来源是包装的确定性前馈注入 `0.66·wz`（ONNX 差动分量为零，见"已确认"第 4 条），命令差 ≈1.4–1.5 rad/s 恒定；轮端是 kp=0、kd=2、无前馈的纯速度环，其可产生的每轮差动力矩被结构性地封顶在 `kd×(命令差/2) ≈ 1.5 Nm`（全失速极限）。实测 tau 峰值 1.6–3.4 Nm/轮、`tau_est ≈ 2×(cmd−meas)` 斜率 1.89–2.01 全程线性（无死区、无限流、无固件削顶）——速度环停在"可用力矩 = 轮地刮擦阻力"的平衡点，而不是坏了。
2. **实机轮地阻力约为 MuJoCo 的 2–3 倍（约 3 倍，真 sim2real 部分）**：同权重、同包装、同实机 11.6 s 命令波形、同实测初态回放到 MuJoCo：仿真轮差跟踪 ≈29% 且**不塌缩**（−0.27→−0.41→−0.32 rad/s，偏航 38%），实机同窗口 5–11% 且 3–4 秒内塌缩（偏航 13–14%）。摩擦×0.5/×2 单变量显示轮差与偏航随摩擦单调变化，方向一致。

**最能区分剩余解释的单项证据**：MuJoCo 固定腿姿+实机轮目标回放，仅把轮端 kd ×4：轮差跟踪 29%→73%、偏航 86%；×10 到 91%/106%（§四 E4）。它把"力矩权威不足"与"腿姿/策略行为/发布链"干净地分离开。**后腿下沉是伴随/加重因素而非根因**：仿真固定腿姿同样保持轮差不塌缩（E3），实机时间上下沉与塌缩耦合但无接触力证据，不能断定因果。

**优先修复项（部署端最小修正）**：把转向差动从纯开环注入改为**有界偏航率反馈注入**（`wz_eff = wz_cmd + Kp·(wz_cmd − gyro_z)`，输出限幅；快速仿真 Kp=3 已验证 89% 跟踪、0 非轮触地），作为独立部署候选走完整门槛（§六）。训练端根治项为同事已建的 `r4000-turn-20k` 手册（驻留 6–15 s、独立差动残差、稳态偏航奖励、后小腿净空——与本报告证据一致）。

## 三、部署链路源码审计（二.1）

审计 `r4000_controller.cpp`（会话版 SHA `92c0d442`）+ `common/as2w_publish.cpp`（会话版 `10c463f3`）轮路径：

1. **差速前馈**：唯一差动源 = `rolling_fixed_exit` 的 `−0.66·(1+0.25·steering)·wz·side`（r4000_controller.cpp L161–165；训练同式、parity 1.155e-07 已验证）。`pure_turn_common_scale=0` 在本部署**实际编译生效**（源码硬编码 `turn_common = common·forward_blend`）。
2. **偏航误差反馈**：**不存在任何已启用的偏航反馈路径**。源码中的反馈项仅有两个：(a) 0.12 s 轮位置锁存 `−6·err/16`——以"命令居中"为门，长转期间 0 帧启用（数据验证）；(b) 站姿 bias 积分——以 `activity<0.05` 为门，运动期间关闭。gyro 仅进入观测（策略输入）与上述门控，不进差动。
3. **动作裁剪/符号/单位/限幅**：轮 raw 裁 ±1 进 common/steering；轮 dq=16×wrapped 裁 ±98.47；槽位/符号经发布映射（自推导验证）；`wheel_step` 守卫 15/30 rad/帧未触发（命令斜坡经 0.1 rad/s² 摇杆斜率）。任务书中"旧包装已有的可选陀螺反馈和轮差校正"（turn-20k 手册 §3）：在部署源码与训练包装源码中均未发现除上述 (a)(b) 外的轮差反馈实现——该表述应指 (a) 或计划项，**本部署未启用**。
4. **ONNX 差动分量为零**：会话全部 4157 运动帧回放，`wheel clip fraction=1.0`、side 加权 steering range **[0.0, 0.0]**（+6,+6,−6,−6 前后反对称模式，左右无差）。独立于先前结论：本复算逐帧直接从会话 raw 计算确认。

## 五、结论分级

**已确认（直接证据）**
1. 链路 0 损失到手柄→…→最终发布：源码重算=记录目标（1.4e-06），applied=发布（100%），槽位/符号/单位自洽。
2. ONNX 轮差动分量恒零（4157 帧直接复算）；差动唯一来源是 0.66 开环注入；部署无任何已启用偏航反馈。
3. 轮速环纯速度模式（kp=0/kd=2/tau=0），`tau_est≈2×速度误差` 全程线性（斜率 1.89–2.01），无死区/限流/守卫触发证据；tau 峰值 ≤3.4 Nm/轮 ≈ 该环结构性上限。
4. 实机长转轮差塌缩至命令的 5–11%（3–4 s 内），短转 58–105% 不塌缩；塌缩与后蹲姿态存在性强相关、无固定先后；保护位全零、通信龄正常。
5. MuJoCo 同权重同命令波形同初态：轮差跟踪 ~29% 且不塌缩（偏航 38%）——**塌缩与 ~3× 幅差均为实机侧独有**。

**证据支持**
1. 缺口分解 ≈ 轮速环结构性力矩上限（~3×，kd×4 仿真单变量：29%→73%）× 实机轮地阻力高于仿真（~3×，摩擦单变量单调 + E1 对比）≈ 8–10×。
2. 后腿下沉为伴随/加重因素（固定腿仿真不改变塌缩行为；实机时序耦合），非根因。
3. 有界偏航反馈（Kp=3）可把偏航跟踪提到 ~89% 且无触地——最小修正方向有效。

**仍需验证**
1. Isaac Lab 同口径对照（caolin 不可达；命令已备）。
2. 实机轮地摩擦/胎压/地面状态未测——"实机阻力 ~3×"是由行为反推的，无独立摩擦测量。
3. 固件电流环/内部限矩细节（无驱动器文档与逐轮电流遥测；现有证据只表明 tau_est 线性且远低于守卫，不排除低速下未显现的固件行为）。
4. Kp=3 闭环的 1 个失败种子（驻停未过）与守卫参数（8/12 Nm）在更长/负载工况下的余量。
5. MuJoCo 摩擦为各向同性（无法单独调横向刮擦），"横向摩擦敏感性"以各向同性近似。

## 六、优先修复项与复验门槛

**优先修复（部署端最小修正）**：有界偏航率反馈注入（独立候选 `AS2W_R4000_YAW_FB`，默认关闭）：
`wz_eff = clamp(wz_cmd + Kp·(wz_cmd − gyro_z_body), ±0.15)`，仅作用于差动注入项，观测命令通道与 previous-action 保持原合同；Kp 初始 3、限幅 ±0.15（比快速实验更保守）。
**复验门槛**（全过才可谈实机）：① 同合同 MuJoCo 全矩阵（直行 0.05–0.4、转 ±0.05/±0.1 各 ≥10 s、弧线、驻停，12 种子含 46005/46006，推扰+2% 丢包）：偏航后 5 s 跟踪 ≥70%、无非轮触地、直行回归不劣化；② x86/ARM64 独立构建+parity（对照带同反馈的参考实现）+audit+双端 SHA；③ 实机阶梯：zero-B → 0.05 rad/s 短转（点动）→ 0.1 rad/s，每级当次许可。
**训练端**：`r4000-turn-20k` 手册方向正确；建议补两项证据：(a) 训练命令分布纳入 ≥10 s 持续转（现 1.1–3.4 s 驻留仍是塌缩盲区——E1 显示塌缩在 3–4 s 才发展完）；(b) 域随机化把轮地摩擦上界扩到实机反推值（≥仿真 ×3），否则仿真侧永远复现不了 5–11% 平衡点。

2. 支架轮离地：B 零速下逐轮阶跃 ±0.5/±1.0 rad/s 命令（现有 Debug 链即可），测空载轮速环响应（标定 kd 实效与延迟）；
3. 转向窗口的轮端电流/驱动器状态遥测（若 SDK 可读）：验证 tau_est 与真实电流的比例（区分固件限矩可能性）。
采样：现有 2 ms 快采 + 50 Hz Debug 即可，无需新增通道；每项 ≤10 s、趴姿或支架、逐次授权。
