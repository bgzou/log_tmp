# R1199 仿真差异：同条件复演与改进方向

日期：2026-11-11。全程只做离线仿真。训练服务器仅通过 SSH 读取、复制源码和评估合同；**没有修改其文件或启动其训练/评估**。仿真运行在 `caolin@192.168.10.163` 的 `/tmp/opencode/`，权威记录存本机 `部署测试/04_调试记录/logs/`。

## 结论

**先前“R1199 在实测起步姿态下必然右后小腿碰地”的判断不成立。** 本项目旧复演器把 ONNX 的**原始输出**作为下一帧观测的 `previous_action`；训练方评估器使用的是经过 `rolling_fixed_exit`、站姿补偿和轮子保持后的**包装后归一化动作 `current`**（进入交接 blend 之前）。这是 65 维观测中 `[42:58]` 的语义差异，而不是权重、MuJoCo XML 或接触阈值差异。旧复演器 seed 202 无推扰首次 `RR_calf` 触地在运动后 1.440 s，整段峰值 98.9 N；只修正上一动作回填，保留原低摩擦、随机质量/增益、直接力矩 PD、0.30 m/s 突然指令及原计划推扰后，seed 202 **0 N 非轮接触**、平均前进约 0.305 m/s。seed 101/303 同样无非轮触地且能跟踪、刹车。

**R1199 仍未通过完整操作链。** 修正后我方三种子 `fixed_exit_ok=0/3`，回固定站姿尾段最大腿角误差约 0.222–0.251 rad，超过我方 0.18 rad 门槛；训练方正式 Isaac 0.30 m/s 完整链仅前进 1/20、倒退 2/20，`gate=false`。训练方原生 MuJoCo 6 个场景也全部未完整通过、`gate=false`。因此可以说它具有低速前进和刹车的仿真能力，不能说已经具备可靠停车保持和策略退出能力，更不能直接绑定真机 B。

真机发布端专项核对：R1199 尚无 `cpp_deploy-as2w` 控制器/launcher，旧复演器错误没有进入 R1199 LowCmd；已运行的 R214 是 `obs41+state1196`，不含这个上一动作字段。R284 虽为65维，但其官方适配器回填的是裁剪后的动作，未发现同一种 raw-vs-wrapped 错误；R284 真机振荡仍属独立未解事故并继续禁止运行。详见调试日志 `logs/20261111_r1199_real_deploy_history_audit.md`。

- `r1199_colleague_ablation_patch.py` 从只读快照生成 `r1199_colleague_eval_ablation.py`，仅增加可选 `seed=202`、实测 FixedStand 关节角及 pitch `−5.498°`、单场景前进和控制帧记录。原生/实测初态均使用训练方自身的动作包装、native PD、预标定站姿、轮角保持和停车里程计。实测初态根高度由接触搜索给出 `0.38016 m`，并非真机测得。
- `r1199_legacy_ablation.py` 是我方旧复演器的独立副本，环境开关分别控制摩擦、随机质量/增益、native PD、指令渐入、上一动作回填；原复演器未修改。两个副本均在 caolin 离线运行，无 DDS/LowCmd。

## 同一 seed 202 的因果消融

下表的“碰地”均指运动期非轮触地。训练方评估器对**任何**非轮接地即计失效；我方旧复演器使用 `>1 N` 记录，原始 24.13 N 首次接触和 98.9 N 峰值远超该差别。

| 评估器与条件 | 碰地 | 关键结果 |
|---|---|---|
| 训练方原生初态、native PD、无推扰、seed 202 | 无 | 跟踪通过、停车保持未通过 |
| 训练方注入实测 q/pitch，其余同上 | 无 | 跟踪通过；`fixed_entry_s=0`、`fixed_final_s=0`；最终腿角误差 0.244 rad |
| 我方旧复演器，原随机应力，**原始动作回填**，无推扰 | 有 | `RR_calf` 首触 1.440 s；整段峰值 98.9 N |
| 旧复演器仅把摩擦改为 0.70 | 有 | 峰值 81.5 N；首触推迟到 1.954 s |
| 旧复演器仅去掉随机质量/增益 | 有 | 峰值 76.5 N |
| 旧复演器摩擦 0.70、名义动力学、native PD、0.25 s 指令渐入，仍用原始动作回填 | 有 | 峰值 72.0 N；改物理与指令时序仍未消除 |
| 上一行仅把回填改为**最终包装动作** | **无** | 约 0.301 m/s，刹车通过，完整回站仍失败 |
| 我方原低摩擦、随机质量/增益、直接力矩 PD、无渐入、原推扰，仅修回填 | **无** | seed 202 约 0.305 m/s；seed 101/303 也均无碰地、跟踪和刹车通过 |

控制帧定位：在运动开始时，旧复演器与训练方的 65 维观测 `previous_action[42:58]` 最大相差 **6.328**（旧值可达 `−6`，训练方约 `0.328`）；轮角记忆 `[60:64]` 也不同。约 1.44 s 时，旧复演器机身 pitch 约 `−0.24` 至 `−0.32 rad`（依扰动设置），训练方实测初态复演约 `+0.10 rad`；旧复演器右后大腿约 `0.56 rad`、右后小腿约 `−1.92 rad`，训练方约 `0.92/−1.62 rad`。它们在接触前已经进入不同的闭环轨迹。动作回填的单变量修正消除了接触，证明其是本例的主导原因；其他观测/停车差异仍需正式逐帧对齐。

## 停车和回站的独立问题

训练方评估器注入实测 q/pitch 的 seed 202：无非轮接触，前进跟踪与刹车通过；但停车后 10 s 位移峰 `0.02059 m`，略高于 `0.020 m`；速度 95 分位 `0.03055 m/s`，高于 `0.020 m/s`。最终腿角最大误差 `0.244 rad`，其最近 100 帧的 `joint_pose <0.18 rad` 全部失败，**同一窗口的轮子承重、机身直立、水平速度和偏航速度四项全通过**。我们自己的修正后 seed 101/202/303 回站尾段误差 `0.249/0.222/0.251 rad`，所以不是一次随机触地造成的回站评分失败。

这里的 0.18 rad 是评估门槛，不是机器人厂商的硬件保护限值；真机已稳定 FixedStand 的腿误差约 0.27–0.30 rad，因此目前的回站评分很可能把**可稳定负载的姿态**判为失败。不能仅凭这项推断会摔倒，也不能简单把门槛放宽来宣称完整通过：需要把**策略→回站过渡是否平顺、稳定承重姿态、轮子刹停、机身漂移和关节余量**分开核验，再设计负载参考与可达目标。

## 哪套判定更合理

1. **判断策略原本能否运动**：训练方的原动作包装与“最终动作回填”语义更可信；我方先前“98.9 N 碰地”来自实现错误，应从权重风险证据中撤销，历史视频只保留作错误复演说明。
2. **判断能否部署到这台狗**：训练方仅仿真 reset 的试验不够；应在其正确控制器里加入实测 q/pitch、负载站姿偏差、关节/轮速/电流/时间延迟和控制权切换。此次注入已显示固定站姿入口与出口不达门槛。两套现有报告都不能单独作为真机放行依据。
3. **当前判断**：R1199 可以继续做离线优化，尚不能完整绑定 B。仅按“没有非轮碰地”放行会漏掉停车保持与回站失败；仅按旧视频说“策略肯定会碰地”则会误杀有效前进能力。

## 后续改进顺序

1. **先锁定观测合同**：部署 C++、ONNX 影子、MuJoCo 评估都逐帧断言 `obs[42:58]` 等于上一帧最终归一化腿/轮动作；`obs[60:64]` 的轮角记忆与 `ZeroWheelMemory` 对齐；核对命令低通、0.62 s 相位钟、动作限幅、站姿补偿和停车里程计。新增一条 100 帧固定输入的跨实现数值回放，不允许“能跑”代替语义一致。
2. **用真实起步链复演**：补采实机 FixedStand 的连续 LowState、IMU、四轮角/速度和加载姿态；在训练方正确控制器中回放 A→固定站→B 交接。根高度和机体速度当前未实测，需做范围扫描。逐帧保存 obs、raw action、包装后 action、最终 q/dq、实际力矩、轮载及首次非轮触地，避免只看阶段峰值。
3. **集中改停车和回站**：对 0.30→0 指令做 10 s 保持，目标是速度、漂移、轮子保持都过关；对策略末端腿姿使用**负载平衡参考**或经过验证的重力/力矩前馈，再做连续插值回固定站。先消除 `0.22–0.25 rad` 的系统性偏差，再评估退出。前馈力矩应从当前策略和真实承载状态测得，不能直接套其他机器人的数值。
4. **正式重新验收**：同一权重、同一观测/包装、同一资产，做 ≥20 种子前进/倒退/左右转、零速 10 s、停止再起步、策略退出；Isaac 与 MuJoCo 两端复核非轮接触、轮卸载、关节限位、力矩、倾倒、停车/保持。对延迟、丢包、低摩擦和实测负载姿态单独扫参。记录每项分子/分母；完整链达标后再讨论有界实机首测。
