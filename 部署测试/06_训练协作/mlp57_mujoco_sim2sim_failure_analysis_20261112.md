# AS2W MLP57 (model_2700) MuJoCo sim2sim 失败分析——给训练侧

日期：2026-11-12。部署侧 caolin 服务器，MuJoCo 3.17 + 官方 URDF 同源模型（26kg、力矩限 60/60/90/15、接触高度与你们 0.42844−0.005 完全吻合）。所有数据可复算，脚本随附。

## 一、结论

**我们的 MuJoCo 第二仿真器验证未通过**：stand 都站不稳（闭环 12s 内倾翻或大幅振荡，tilt 峰 44–178°），对照你们 PhysX 156/156 生存。

**失败不在移植，在物理引擎的轮地静摩擦保真**：这台策略的低速稳定性完全依赖被动静摩擦，而 MuJoCo 对轻质量轮子的软化摩擦约束给不出 PhysX 那样的"锁死"行为。

## 二、移植正确性（先排除我们的问题）

- obs 构建 vs 你们 `native_samples.npz` 6000 帧录制：**4.8e-08**；ONNX 推理 vs 录制 raw：**1.3e-06**。
- 轮位四维 obs[21:25] 恒零：已正确实现（你们录制也是全零，本次复验）。你们 B2W 适配器那次 1.72s 失稳的零填充 bug，我们这边没有。
- 关节序/符号/轮向（前进=+dq）、质量惯量、PD 40/1 与 0/1、力矩限、入口姿态、初高度（接触+5mm）逐项核对一致。
- **发现一处你们文档没写清的语义**：你们的 Isaac 执行器 PD 是**每个物理子步（5ms）重算**的（"zero-order target hold"指目标保持，力矩每子步刷新；帧 0 轮力矩 +0.077 是末子步对已加速轮的刹车值，而帧首力矩 −1.31）。按 50Hz 力矩保持实现会轮速发散。建议写进 effective_runtime——任何自定义力矩路径的部署端都必须知道这一点。

## 三、核心证据：轮静摩擦单元测试

机器人模型、双腿用大 PD 锁死、轮压地 57N、摩擦 1.0（你们正式评估的标称值）、只给轮加 1 Nm（摩擦容量 μ·N·r ≈ 4.9 Nm，远未饱和）：

| 引擎 | 轮子表现 |
|---|---|
| 你们 PhysX | **0 rad/s，完全锁死**（stand 稳态轮 dq≈±0.1 的录制可证） |
| 我们 MuJoCo | **1.5–2.3 rad/s 恒速爬行**（摩擦只给出"恰好抵消"的力矩，不进入锁死态） |

已排除：法向力弹跳（实测 58±0.8N 稳定）、网格顶点跳变（换解析圆柱更差）、摩擦系数（0.62→1.0 已对齐）、求解器参数（impratio/noslip/solimp/cone/Euler-implicitfast-implicit 全试无效）、模型几何质量（同 URDF/STL）。**对照实验**：25kg 刚体底盘+同款轮的最小模型同样设置能锁住（0.12 rad/s）→ 差异确实在"0.595kg 轻轮挂腿链末端"的小有效质量上——MuJoCo 的软化摩擦约束对这种结构天然偏软。

## 四、连锁后果与对照

- 策略 stand 稳态输出非对称轮指令（±0.3–1.7 rad/s）：PhysX 里被静摩擦完全吸收；我们这里轮子爬行 → 机体缓慢漂移后仰 → 策略从没见过这些状态 → 振荡/翻倒。开环注入你们录制的 stand 动作序列复现：你们 0.419 直立 vs 我们沉到 0.32m、后仰 33°、后小腿撑地。
- **对照 R1199**（我们的另一条线）：它的包装有主动轮控（停车时轮速 = −6×轮角误差/16 强反馈），不依赖地面摩擦保真 → 在同一个 MuJoCo 模型上一切正常。**差别不在引擎，在策略的低速稳定策略**：R1199 靠主动控制，mlp57 靠被动静摩擦。

## 五、判断与建议

1. 真机静摩擦是真实存在的（电机堵转/轮地不打滑），**PhysX 的行为更接近硬件，MuJoCo 是这里的异类**——这不构成"策略上真机会失败"的证据，但按 v3 交付合同 R2（第二仿真器）门槛，当前不过，我们不绑定按键上实机。
2. 你们修 B2W MuJoCo 适配器（零填充 bug）之后，大概率会撞上**同一个摩擦问题**——上面的单元测试可以直接拿去验证。
3. 三条出路，按我们建议排序：
   - **a. 出带主动轮控/停车站姿包装的版本**（像 R1199 那样不依赖被动摩擦）——最稳，也最接近你们 reanchor 预览已经在做的方向；
   - b. 你们侧跑通自己的 MuJoCo 闭环（渲染管线已有，加上面单元测试先验证摩擦）；
   - c. 换一个摩擦保真更好的第二仿真器。
4. 另外注意到训练采样器把 XY 合速度 <0.2 m/s 的命令清零（低速覆盖缺口），以及已有 model_6000/7500（±1.5 m/s 续训）——若出包装版，请一并给最终推荐 checkpoint 和对应合同。
