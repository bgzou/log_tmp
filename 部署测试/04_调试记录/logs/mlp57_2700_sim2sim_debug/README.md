# mlp57 (as2w_mlp57_flat_model2700_v1_20261112) MuJoCo sim2sim 调试存档

## 结论：我们的 MuJoCo 第二仿真器验证不通过（非移植错误）

- 移植链**逐位正确**：obs 构建 vs 他们 6000 帧录制 = 4.8e-08；ONNX 推理 = 1.3e-06；
  关节序/符号/轮向/增益全部核对；模型质量(26kg)/惯量/URDF 同源一致。
- **发现关键合同语义**：他们的 Isaac 执行器 PD 每个**物理子步(200Hz)重算**（目标保持、
  力矩刷新；帧0轮力矩 +0.077 为末子步刹车值可证）。50Hz 力矩保持 + kd=1 会轮速发散。
- **根因**：MuJoCo 对本模型"轻有效质量轮链"的静摩擦保真不足——58N 法向、μ=1、
  1Nm(容量5Nm)下轮恒速爬行 1.5-2.3 rad/s（法向力稳定无弹跳、非网格顶点问题、
  换解析圆柱更差、impratio/noslip/solimp/积分器均无效）。最小模型(刚体底盘)同样
  设置则锁住(0.12 rad/s)。
- 连锁后果：策略 stand 稳态的非对称轮指令(±1.7 rad/s)在 PhysX 里被静摩擦完全吸收，
  在我们这里爬行→漂移→后坐；开环注入他们的动作序列 → 后坐 0.32m/+33°。
- 闭环：solref 全谱(0.02→0.001)均不稳定（振荡或翻转，tilt 峰 44-178°），
  无可用窗口。默认 0.02 可存活 12s 但大幅振荡（h 0.23-0.53）。
- 策略类别本身依赖被动轮静摩擦做低速稳定——对第二仿真器摩擦保真度极敏感。

## 判定
按 v3 交付合同 R2（sim2sim）：**未通过**。不建议绑定 B 键上实机。
PhysX 156/156 生存证据不受影响；失败隔离在 MuJoCo 摩擦保真，非策略移植或权重缺陷证据。
后续选项：训练方自跑第二仿真器/改用其他引擎；或改进我们模型的轮接触建模后重试。
