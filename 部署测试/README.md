# AS2-W × CPRO 现场部署工作区

**从 `02_现场操作/参考资料总审计.md` 和 `02_现场操作/明日bringup手册.md` 开始。** 推理目标是 CPRO 鸿蒙内的 Ubuntu 环境；AS2-W 的 Orin 拓展坞只提供网络接入，不运行策略。

| 目录 | 用途 |
| --- | --- |
| `00_HDC工具/` | 已在本机验证可运行的 HDC exe + DLL、来源与连接说明。 |
| `01_现场部署包/` | 拷到 CPRO 的两个 tar.gz 和 SHA-256 清单。 |
| `02_现场操作/` | 分阶段操作清单、部署架构、GO2 文件移植判断、策略选择与测试、部署工程说明、官方资料核对、CPRO 问题、硬件合同。 |
| `03_官方资料/` | 现场要用的宇树离线 HTML 页面与图片资源快照。 |
| `04_调试记录/` | 阶段总账、模板和从 CPRO 复制回来的原始日志。 |

源码唯一维护位置是 `../部署参考/cpp_deploy-as2w/`。修改源码、模型或说明后，在此目录运行 PowerShell 脚本 `./准备现场包.ps1` 更新压缩包和资料快照。不要直接改 `01_现场部署包/` 内的归档。

当前已在本机完成模型校验，并准备好 CPRO 预检、DDS 只读检查、原厂高层动作和影子推理工具；后四项尚未上机验收。**AS2-W 16 轴低层电机发布端尚未接通**；缺四轮 DDS 槽位、轮速写入语义等现场合同，详见 `02_现场操作/低层硬件合同.md`。原厂遥控器可先用于原厂高层控制；CPRO 读手柄输入的 `rt/wirelesscontroller` 需现场验证。

`cpp_deploy-as2w/deploy/robots/as2w/config/config.yaml` 与 `tools/field.sh policy-*` 现在可按名字选择六份权重做离线核对，三份爬楼权重在映射核实后可做只读影子推理。它们还不是 GO2 式真机策略切换 FSM；最终模块结构、当前实现状态和后续顺序见 `02_现场操作/部署架构.md`，两类策略的具体测试命令见 `02_现场操作/策略选择与测试.md`。
