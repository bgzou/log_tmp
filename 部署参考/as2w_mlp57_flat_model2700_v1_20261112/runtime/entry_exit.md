# 入口、零速与退出

本包只声明从标称四足站姿开始的平地滚动候选。初始腿角按 FR/FL/RR/RL 各为 [0,0.65,-1.3] rad，初始机身高度 0.4284399501 m、关节与根部速度为零；正式验证还包含 3 组固定微小扰动（腿角±0.005 rad、倾角±0.25°及不同全局航向），精确值见原始 summary.json。

这是仿真参考姿态，不是对原厂站姿的测量或承诺。训练有大幅随机倒地重置，但本包未声明倒地恢复能力。策略内部不调用 FixStand、教师或原厂运控；外层必须先把本体带到合适初态，接管插值和控制权交接尚未验证。没有把首帧目标强行对齐实测 q 的补偿。

启动/重置时 previous_raw_action 的 16 维清零；无相位、积分器、RNN 隐状态和历史堆叠。每次推理后只将 raw_action 保存为下一帧 previous；松杆或命令切换不清零该状态。57维观测中的4个轮位置槽在加训练噪声前置零，不能填入轮角。

零命令只是 Actor 的零机体速度请求，策略会自己输出腿角/轮速；不等于刹轮、锁轮角、固定世界位置或退回固定PD站。原测试含2秒零命令停车，验收看最后1秒平均平移≤0.1m/s、平均绝对偏航≤0.15rad/s。没有长时间驻停、刹停力矩、失联和动作退出的真机证据。原测试没有显式规划制动距离。

模型是持续控制器，没有自主“动作完成”信号。仿真里的20秒 time_out 不是部署的停止条件。停止推理或失联后整机如何制动、保持或交回原厂控制，由部署外层定义；本包不发布 LowCmd，也没有默认 DDS 超时动作。
