# 部署侧待核硬件合同

joints.csv 的顺序是策略/URDF顺序，不是经验证的 DDS 电机槽位表。正方向严格取所附 URDF 的局部轴和 origin，不根据其它机型推断。config/quadruped_recorded_sample.json 只是一次只读记录，用来溯源本次标称 PD 40/1 与轮 0/1，不能代表所有固件或状态。

部署方须为这台机器另行提供：16个符号关节到DDS槽位的映射、编码器零位/正负号、轮轴模式/单位/齿轮比、IMU到base_link旋转、LowCmd字段和校验、控制权交接、接管前置姿态、实际电机周期与超时退出。该合同目前 not_validated。

腿 q/dq/kp/kd/tau_ff 和轮 q/dq/kp/kd/tau_ff 的标称请求已给出；仿真腿使用DC电机近似后变成受转速/力矩限幅的力矩，轮使用PhysX隐式速度驱动。请求值不保证和实际固件的电机内环完全等价。硬件限幅、滤波或补偿如与本包不同，应作为新的运行时版本记录并重做离线对齐。
